## 📌 Project Description
As first-year students transitioning into campus life, managing academic workload, daily routines, and stress can be overwhelming. **MoodCraft** is a lightweight, easy-to-use mental wellness web app built by **Team CodeCrafters** to help students track their daily emotional well-being without spending hours writing long diaries.

With MoodCraft, a student can record their mood in under 10 seconds using a simple 5-emoji rating scale, add short daily reflection notes, view interactive visual charts that show how their mood changes over the week, and immediately access an SOS emergency helpline (`+91 6370670184`) and breathing exercises whenever they feel stressed or overwhelmed.

---

## ✨ Key Features

1. **Interactive Human Verification:**
   * A clean onboarding gateway with a bot-check captcha to ensure genuine daily check-ins.

2. **5-Level Mood Logger:**
   * Log daily moods from *Awful* (😫) to *Great* (🤩) along with optional notes about your day.

3. **Visual Mood Trend Graph:**
   * Integrated line charts powered by **Chart.js** that automatically plot emotional scores (1 to 5) and calculate an overall average mood score.

4. **Automated Breakdown & SOS Assist:**
   * If a user selects the *Awful* mood rating, the application automatically opens an emergency help modal featuring:
     * Direct calling to helpline: `+91 6370670184`
     * Instant one-tap WhatsApp support
     * A 4-4-6 guided breathing relaxation exercise

5. **100% Privacy & Instant Loading:**
   * Built using browser `localStorage`, meaning student data stays safe on their own device with zero login hassle and zero latency.
